# fuzzing_course

Курс по фаззингу: afl, libFuzzer, Atheris + lizard для цикломатической сложности. Практика на материалах из `fuzz-builder.tar` (артефакты пространства с обёртками). Рабочая среда — контейнер (фаззинг-утилиты на хост не ставятся).

## Agent skills

### Issue tracker

Локальный markdown: тикеты — файлы в `.scratch/<feature>/issues/NN-<slug>.md`, спеки — `.scratch/<feature>/spec.md`. See `docs/agents/issue-tracker.md`.

### Triage labels

Пять канонических ролей, строки по умолчанию. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` в корне. See `docs/agents/domain.md`.
